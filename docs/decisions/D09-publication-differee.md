# D09. Publication différée et dates sans heure

- **Date :** 2026-10-22
- **Statut :** validé

## Décision
- Publication différée **optionnelle**, avec décalage aléatoire.
- Seules les **dates** sont affichées, sans l'heure.

## Raison
Réduire le recoupement par les heures de publication entre pseudonymes d'une même personne (voir 03, modèle de menaces).
